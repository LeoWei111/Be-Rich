怎么用

核心概念
  • 我的利润 ＝（收入 − 成本）× 分成比例。每个副业比例不同（25%~75%）。
  • 应得 / 已入账：在该工具里登记即视为已入账，所以「应得」就是「已入账」。
  • 取现：从账户取出的现金，单独在「录入 → ②」登记。
  • 银行留存 ＝ 应得 − 取现；在手现金 ＝ 取现合计。
预置了什么

《副业财务管理-历史数据.xlsx》的累计（截至2026.05）作为期初基数；《副业财务管理-2026年6月.xlsx》作为第一条月度记录（2026-06）。取现历史未记录，需你从 2026-06 起自行补登。

日常操作
  • 每月底：在「数据录入 → ①」逐个项目填收入、成本，保存。
  • 每次取现金：在「数据录入 → ②」登记月份、账户、金额。
  • 随时：用顶部「查看月份」切换，或在各页签看可视化。
  • 换设备/月底：在「备份」导出 JSON；新电脑导入即可。
数据保存在本机浏览器的 localStorage。若清空浏览器数据会丢失，请定期导出 JSON 备份。
